# Page topology — Triomax header adaptation

1. `SiteHeader` — sticky global header.
   - Desktop/tablet: secondary link bar → logo/action row → category navigation.
   - Mobile: compact action row → optional navigation drawer.
   - Interaction: scroll-driven compression; click-driven search and drawer.
2. `AnnouncementMarquee` — promotional ticker in document flow, immediately after the header and before hero/page content.
3. `HeroSection` or page content — begins below the announcement ticker.

The reference is the Saint Germain header only. The rest of the Triomax storefront remains unchanged.
